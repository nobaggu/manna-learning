# Manna Learning — AI 융합 학습 기록

> 사회학과 학부생이 AI Rookie 대회 준비를 위해 진행한 자기주도 학습 기록.

## 동기

본 학습은 ai rookie 대회 참여를 위한 사전 학습으로,
멘토-멘티 매칭을 통한 사회적 자본 비대칭 해소 프로그램을 구현하기 위해 필요한 AI 지식을 체계적으로 익히는 과정입니다.


## 학습 일정 (5주 계획)

| 주차 | 주제 | 상태 |
|------|------|------|
| Week 1 | basic rag | ✅ |
| Week 2 | hybrid retrieval | ✅ |
| Week 3 | Self-RAG (자기검증 LLM) | ✅ |
| Week 4 | Graph RAG (지식 그래프 기반 검색) | ✅ |
| **Week 5** | **추천 시스템 (MF → NeuMF → LightGCN → SOTA)** | 🔄 진행 중 |


## 활용 기술
- Python 3.11 / NumPy / PyTorch / PyTorch Geometric
